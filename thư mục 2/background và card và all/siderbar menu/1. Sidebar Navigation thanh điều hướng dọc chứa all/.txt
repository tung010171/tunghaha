Phân Tích Tổng Quan & Hướng Triển Khai — Astra Sidebar Navigation

---

I. PHÂN TÍCH TỔNG QUAN

1. Mô hình hoạt động (Mental Model)

Sidebar là off-canvas drawer: panel nằm ngoài viewport (translateX(-150%)), được kéo vào trong (translateX(0)) khi mở. Không dùng display:none để giữ transition mượt. Overlay và hamburger là hai điều khiển phụ phối hợp trạng thái với panel qua class chung.

```
Trạng thái ĐÓNG:  sidebar(translateX -150%, opacity 0) + overlay(ẩn) + hamburger(hiện)
Trạng thái MỞ:    sidebar(translateX 0, opacity 1)     + overlay(hiện) + hamburger(ẩn)
```

2. Kiến trúc 3 lớp phối hợp

Lớp Phần tử Vai trò z-index
Nền .overlay Làm mờ + bắt click đóng 30
Điều khiển .hamburger Mở panel 50
Nội dung .sa-sidebar Panel điều hướng 40
Nền trang .main-content Nội dung chính mặc định

Thứ tự z-index: hamburger (50) > sidebar (40) > overlay (30) — hamburger luôn nổi trên cùng nhưng bị ẩn bằng .hidden khi panel mở để tránh trùng chức năng.

3. Cấu trúc 4 vùng trong panel (flex column)

```
.sa-sidebar (flex column, height = 100% - 2×1.5rem)
├── .sa-header      (height 80px, flex-shrink 0)   → brand + nút X
├── .sa-search-wrap (flex-shrink 0)                → ô search
├── .sa-nav-container (flex:1, overflow-y:auto)    → vùng cuộn duy nhất
└── .sa-footer      (height 80px, flex-shrink 0)   → profile
```

Điểm then chốt: chỉ nav-container có flex:1 + overflow-y:auto, nên header/footer luôn cố định, nav tự cuộn khi nội dung dài.

4. Cơ chế đóng/mở (4 trigger)

Trigger Hành động Cơ chế
Click .hamburger Mở openSidebar()
Click .close-btn (X đỏ) Đóng closeSidebar()
Click .overlay Đóng closeSidebar()
Phím Escape Đóng (nếu đang mở) kiểm tra contains('is-open')

5. Hướng triển khai (thứ tự thực hiện)

1. Design tokens (:root) — khóa màu, radius, width, font trước.
2. Layout khung .desk + .overlay + .hamburger + .sa-sidebar (position/transform).
3. 4 vùng panel dựng từ trên xuống (header → search → nav → footer).
4. Trạng thái CSS: .is-open, .active, .hidden, :hover, [aria-current], :focus-within.
5. Transition: transform + opacity + cubic-bezier(0.4, 0, 0.2, 1).
6. JavaScript: 3 listener click + 1 listener keydown.
7. Kiểm tra a11y: aria-label, aria-current.

script.js

```javascript
const hamburger = document.getElementById('hamburger');
const sidebar   = document.getElementById('sidebar');
const overlay   = document.getElementById('overlay');
const closeBtn  = document.getElementById('closeBtn');

function openSidebar() {
  sidebar.classList.add('is-open');
  overlay.classList.add('active');
  hamburger.classList.add('hidden');
}

function closeSidebar() {
  sidebar.classList.remove('is-open');
  overlay.classList.remove('active');
  hamburger.classList.remove('hidden');
}

hamburger.addEventListener('click', openSidebar);
closeBtn.addEventListener('click', closeSidebar);
overlay.addEventListener('click', closeSidebar);

document.addEventListener('keydown', (e) => {
  if (e.key === 'Escape' && sidebar.classList.contains('is-open')) {
    closeSidebar();
  }
});
```

III. CÁCH CHỈNH SỬA NHANH (không thêm tính năng)

Muốn đổi Sửa ở đâu
Màu nền panel --sa-panel
Độ rộng panel --panel-width
Bo góc panel --radius-panel
Tốc độ trượt 0.35s trong .sa-sidebar { transition }
Tên brand text Astra trong .sa-brand-name
Thêm link copy 1 khối <a class="sa-link"> trong .sa-nav-container
Đổi link active chuyển aria-current="page" sang thẻ <a> khác
Đổi profile .sa-profile-name / .sa-profile-email
Đổi icon thay path/rect/circle trong <svg> tương ứng

🎯 TÓM 1 CÂU

Sidebar hoạt động theo mô hình off-canvas 3 lớp (overlay mờ z-30, panel z-40, hamburger z-50) — panel 280px bo 24px gồm 4 vùng flex (header cố định 80px, search cố định, nav flex:1 cuộn được, footer cố định 80px); mở/đóng bằng cách toggle 3 class .is-open/.active/.hidden qua 4 trigger (hamburger, X đỏ, overlay, Escape), transition bằng transform + opacity + cubic-bezier; code mẫu tách 3 file HTML/CSS/JS với tokens :root để dễ chỉnh sửa, không thêm tính năng ngoài yêu cầu.
