Tổng quan chung
Mô hình thiết kế giao diện cuộn màn hình (Scroll-driven Gate Reveal) vận hành dựa trên cơ chế kết hợp giữa CSS Viewport cố định và JavaScript lắng nghe sự kiện cuộn. Khi người dùng cuộn chuột, trình duyệt tính toán tỷ lệ cuộn để điều khiển các thuộc tính đồ họa phần cứng (như transform, opacity, và clip-path), tạo hiệu ứng vén màn chắn từ Section 1 sang Section 2 một cách mượt mà.
Mã nguồn mẫu chung
<!DOCTYPE html>
<html lang="vi">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Scroll Gate Reveal - Standard Template</title>
    <style>
        * {
            margin: 0;
            padding: 0;
            box-sizing: border-box;
            user-select: none;
        }

        body {
            background-color: #050508;
            color: #ffffff;
            font-family: -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif;
            height: 250vh; /* Tạo không gian cuộn */
            overflow-x: hidden;
        }

        .viewport {
            position: fixed;
            top: 0;
            left: 0;
            width: 100vw;
            height: 100vh;
            overflow: hidden;
            display: flex;
            align-items: center;
            justify-content: center;
        }

        /* Section 2 nằm ở lớp sau */
        #sec2 {
            position: absolute;
            inset: 0;
            z-index: 2;
            display: flex;
            align-items: center;
            justify-content: center;
            padding: 24px;
            opacity: 0;
            transform: scale(0.95);
            will-change: transform, opacity;
        }

        .card {
            background: rgba(18, 18, 26, 0.85);
            border: 1px solid rgba(255, 255, 255, 0.1);
            border-radius: 20px;
            padding: 48px;
            max-width: 620px;
            text-align: center;
            backdrop-filter: blur(20px);
        }

        .card h2 {
            font-size: 2.2rem;
            margin-bottom: 16px;
        }

        .card p {
            color: #a1a1aa;
            line-height: 1.7;
        }

        /* Section 1 nằm đè lên trên làm màng chắn */
        #sec1 {
            position: absolute;
            inset: 0;
            z-index: 3;
            background: #050508;
            display: flex;
            flex-direction: column;
            align-items: center;
            justify-content: center;
            text-align: center;
            padding: 24px;
            will-change: clip-path, opacity, transform;
        }

        #sec1 h1 {
            font-size: clamp(2.5rem, 5vw, 4rem);
            margin-bottom: 16px;
        }

        #sec1 p {
            color: #71717a;
            max-width: 500px;
        }
    </style>
</head>
<body>

    <div class="viewport">
        <!-- Section 2 -->
        <div id="sec2">
            <div class="card">
                <h2>Nội dung trang sau</h2>
                <p>Giao diện đã được mở khóa thành công sau khi hoàn tất hành trình cuộn chuột.</p>
            </div>
        </div>

        <!-- Section 1 -->
        <div id="sec1">
            <h1>Trang hiển thị ban đầu</h1>
            <p>Cuộn chuột xuống để kích hoạt cơ chế chuyển cảnh.</p>
        </div>
    </div>

    <script>
        const sec1 = document.getElementById('sec1');
        const sec2 = document.getElementById('sec2');

        window.addEventListener('scroll', () => {
            const scrollTop = window.scrollY;
            const maxScroll = window.innerHeight * 1.2;
            let progress = Math.min(Math.max(scrollTop / maxScroll, 0), 1);

            // Xử lý hiệu ứng màng chắn (ví dụ dùng clip-path vòng tròn)
            const radius = (1 - progress) * 150;
            sec1.style.clipPath = `circle(${radius}% at 50% 50%)`;
            sec1.style.opacity = 1 - progress * 1.2;

            // Xử lý hiển thị Section 2 phía sau
            sec2.style.opacity = progress;
            sec2.style.transform = `scale(${0.95 + progress * 0.05})`;
        });
    </script>
</body>
</html>
