Cách làm Overlay Intro — Tổng quan

1. Cấu trúc HTML

```html
<div class="overlay">
  <div class="top-bar">...</div>       <!-- thanh trên -->
  <div class="stage">                  <!-- vùng giữa -->
    <h1 class="greeting">Xin chào.</h1>
    <button class="start-btn">Bắt đầu →</button>
  </div>
  <div class="bottom-bar">...</div>    <!-- thanh dưới -->
  <div class="watermark">01</div>      <!-- số mờ -->
</div>
```

2. Các thành phần & cách làm

Thành phần Cách làm
Nền tối background: #0e0e12 trên overlay, position: fixed; inset: 0
Thanh top/bottom position trong flex column, justify-content: space-between, chữ nhỏ letter-spacing rộng
Stage căn giữa flex: 1 + display: flex + justify-content: center + align-items: center
Chữ "Xin chào." font-size: clamp(), white-space: nowrap
Nút "Bắt đầu →" border-radius: 100px, hover đảo background ↔ color, mũi tên dịch translateX
Thanh progress ::after với transform: scaleX(0 → 1), transform-origin: left
Watermark "01" Chữ cực lớn, opacity: .035, pointer-events: none, góc phải dưới
Ẩn overlay JS thêm class → transform: translateY(-100%) + opacity: 0
Animation vào @keyframes fadeUp/fadeDown + animation-delay so le
60 FPS Chỉ animate transform + opacity, will-change đúng chỗ
Fix tap highlight -webkit-tap-highlight-color: transparent + appearance: none

3. Luồng hoạt động

1. Các thành phần fade in so le (top → greeting → action → bottom)
2. Hover nút → đảo màu + progress chạy
3. Click → overlay trượt lên translateY(-100%)
4. Sau ~1.4s → overlay.remove()

---

Code chung chung

```html
<!DOCTYPE html>
<html lang="vi">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Overlay Intro</title>
<style>
  * { margin: 0; padding: 0; box-sizing: border-box; }
  html, body {
    height: 100%; overflow: hidden;
    background: #0e0e12; color: #fff;
    font-family: system-ui, sans-serif;
  }

  /* ===== OVERLAY ===== */
  .overlay {
    position: fixed; inset: 0; z-index: 9999;
    display: flex; flex-direction: column;
    padding: clamp(1.4rem, 3vw, 2.6rem);
    background: #0e0e12;
    overflow: hidden;
    transform: translateY(0);
    transition: transform 1s cubic-bezier(.77,0,.18,1), opacity .9s ease;
    will-change: transform, opacity;
  }
  .overlay.hidden {
    transform: translateY(-100%);
    opacity: 0;
    pointer-events: none;
  }

  /* ===== THANH TOP / BOTTOM ===== */
  .top-bar, .bottom-bar {
    display: flex; justify-content: space-between; align-items: center;
    font-size: .72rem; letter-spacing: .28em; text-transform: uppercase;
    color: rgba(255,255,255,.45);
    z-index: 5;
    opacity: 0;
    animation: fadeIn .9s .3s ease forwards;
  }
  .top-bar { animation-name: fadeDown; }
  .bottom-bar {
    padding-top: 1.2rem;
    border-top: 1px solid rgba(255,255,255,.08);
    animation-delay: .9s;
  }

  /* ===== STAGE — CHỮ + NÚT NGANG, GIỮA ===== */
  .stage {
    flex: 1;
    display: flex;
    align-items: center;
    justify-content: center;
    gap: clamp(2rem, 6vw, 5rem);
    z-index: 5;
  }

  .greeting {
    font-size: clamp(2.6rem, 6vw, 4.8rem);
    font-weight: 700; letter-spacing: -.03em;
    white-space: nowrap;
    opacity: 0;
    animation: fadeUp .9s .5s ease forwards;
  }

  /* ===== NÚT ===== */
  .start-btn {
    position: relative;
    display: inline-flex; align-items: center; gap: 1rem;
    padding: 1.1rem 2.4rem;
    font-size: .85rem; font-weight: 600;
    letter-spacing: .28em; text-transform: uppercase;
    color: #0e0e12; background: #fff;
    border: 1px solid #fff; border-radius: 100px;
    cursor: pointer;
    transform: translateZ(0);
    transition: transform .4s ease, background .4s ease, color .4s ease;
    /* Xóa tap highlight */
    -webkit-tap-highlight-color: transparent;
    appearance: none; -webkit-appearance: none;
    outline: none; user-select: none;
    opacity: 0;
    animation: fadeUp .9s .7s ease forwards;
  }
  .start-btn:hover {
    background: transparent; color: #fff;
    transform: translateZ(0) translateY(-3px);
  }
  .start-btn:active { transform: translateZ(0) translateY(-1px) scale(.98); }
  .start-btn .arrow {
    display: inline-block;
    transition: transform .4s ease;
    will-change: transform;
  }
  .start-btn:hover .arrow { transform: translateX(6px); }

  /* ===== THANH PROGRESS ===== */
  .progress {
    position: relative;
    width: 160px; height: 1px;
    margin-top: .9rem;
    background: rgba(255,255,255,.12);
    overflow: hidden;
  }
  .progress::after {
    content: ""; position: absolute; inset: 0;
    background: #fff;
    transform: scaleX(0);
    transform-origin: left;
    will-change: transform;
    transition: transform .8s cubic-bezier(.16,1,.3,1);
  }
  .action:hover .progress::after { transform: scaleX(1); }

  /* ===== WATERMARK ===== */
  .watermark {
    position: absolute;
    right: -2vw; bottom: -6vh;
    font-size: clamp(10rem, 26vw, 22rem);
    font-weight: 900; line-height: 1;
    color: rgba(255,255,255,.035);
    pointer-events: none; user-select: none;
    z-index: 1;
  }

  /* ===== KEYFRAMES ===== */
  @keyframes fadeUp {
    from { opacity: 0; transform: translateY(18px); }
    to   { opacity: 1; transform: translateY(0); }
  }
  @keyframes fadeDown {
    from { opacity: 0; transform: translateY(-12px); }
    to   { opacity: 1; transform: translateY(0); }
  }
  @keyframes fadeIn {
    from { opacity: 0; } to { opacity: 1; }
  }

  /* ===== REDUCED MOTION ===== */
  @media (prefers-reduced-motion: reduce) {
    *, *::before, *::after {
      animation: none !important;
      transition: none !important;
    }
  }

  /* ===== RESPONSIVE ===== */
  @media (max-width: 760px) {
    .stage { flex-direction: column; gap: 2rem; text-align: center; }
    .greeting { white-space: normal; }
  }
</style>
</head>
<body>

<div class="overlay" id="overlay">

  <div class="top-bar">
    <span>2025 / 01</span>
    <span>VI · EN</span>
  </div>

  <div class="stage">
    <h1 class="greeting">Xin chào.</h1>

    <div class="action">
      <button class="start-btn" id="startBtn">
        Bắt đầu
        <span class="arrow">→</span>
      </button>
      <div class="progress"></div>
    </div>
  </div>

  <div class="bottom-bar">
    <span>Intro · v1.0</span>
    <span>Cuộn ↓</span>
  </div>

  <div class="watermark">01</div>
</div>

<script>
  const overlay = document.getElementById('overlay');
  const btn     = document.getElementById('startBtn');
  let done = false;

  btn.addEventListener('click', () => {
    if (done) return;
    done = true;
    btn.disabled = true;
    overlay.classList.add('hidden');
    setTimeout(() => overlay.remove(), 1400);
  });
</script>

</body>
</html>
```

---

Lưu ý

· Tôi không chắc code này đạt 60 FPS ổn định trên mọi thiết bị — cần đo bằng DevTools Performance.
· Tôi không chắc khoảng cách clamp(2rem, 6vw, 5rem) giữa chữ và nút phù hợp với mọi kích thước màn hình.
· Nhãn "Cuộn ↓" ở bottom chỉ là trang trí, không có hành động thật.

🎯 Overlay = nền tối + thanh top/bottom editorial + chữ "Xin chào." và nút "Bắt đầu →" nằm ngang giữa màn hình + watermark "01" mờ + thanh progress khi hover, ẩn bằng translateY(-100%), animate bằng transform/opacity.
