Overlay Texture — Cách làm tổng quan

1. Cấu trúc HTML

```html
<div class="overlay">
  <div class="band"></div>   <!-- 4 dải nền -->
  <div class="band"></div>
  <div class="band"></div>
  <div class="band"></div>

  <div class="stage">                     <!-- lớp nội dung -->
    <div class="greeting-wrap">
      <span class="greeting">Xin chào.</span>         <!-- lớp metal -->
      <span class="greeting grain">Xin chào.</span>   <!-- lớp grain -->
    </div>
    <button class="start-btn">Bắt đầu →</button>
  </div>
</div>
```

2. Các bước làm

Bước Việc làm
1 Overlay dùng grid-template-rows: repeat(4, 1fr) → 4 dải bằng nhau
2 Mỗi .band có blueprint grid 40px bằng 2 linear-gradient vuông góc
3 .stage phủ lên trên bằng position: absolute; inset: 0, căn giữa flex
4 Chữ dùng 2 span cùng nội dung: 1 lớp metal, 1 lớp grain
5 Cả 2 span đều dùng background-clip: text + color: transparent
6 Grain dùng mix-blend-mode: overlay, wrapper có isolation: isolate
7 Nút "Bắt đầu" outline vuông bên dưới, fade up
8 Ẩn: .stage fade out + dải lẻ translateY(-100%), dải chẵn translateY(+100%), lệch delay

3. Nguyên tắc để mượt

· Chỉ animate transform, opacity, background-position
· will-change đặt đúng chỗ, không lạm dụng
· mix-blend-mode có thể tốn compositor → chỉ đặt trên chữ, không phủ toàn màn
· Tôn trọng prefers-reduced-motion
· Xóa tap highlight trên nút

Code chung chung

```html
<!DOCTYPE html>
<html lang="vi">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Overlay Texture</title>
<style>
  * { margin: 0; padding: 0; box-sizing: border-box; }
  html, body {
    height: 100%; overflow: hidden;
    background: #05060a; color: #fff;
    font-family: system-ui, sans-serif;
  }

  /* ===== TRANG BÊN DƯỚI ===== */
  .page {
    min-height: 100vh;
    display: flex; align-items: center; justify-content: center;
    background: #0e1420;
  }

  /* ===== OVERLAY — 4 DẢI ===== */
  .overlay {
    position: fixed; inset: 0; z-index: 9999;
    display: grid;
    grid-template-rows: repeat(4, 1fr);
    overflow: hidden;
  }
  .band {
    position: relative;
    background: #05060a;
    transform: translateY(0);
    transition: transform .9s cubic-bezier(.77,0,.18,1);
    will-change: transform;
  }
  .band::before {
    content: "";
    position: absolute; inset: 0;
    background-image:
      linear-gradient(rgba(120,180,255,.05) 1px, transparent 1px),
      linear-gradient(90deg, rgba(120,180,255,.05) 1px, transparent 1px);
    background-size: 40px 40px;
    pointer-events: none;
  }
  /* Ẩn: dải lẻ lên, chẵn xuống, lệch delay */
  .overlay.hidden .band:nth-child(odd)  { transform: translateY(-100%); }
  .overlay.hidden .band:nth-child(even) { transform: translateY(100%); }
  .overlay.hidden .band:nth-child(2) { transition-delay: .05s; }
  .overlay.hidden .band:nth-child(3) { transition-delay: .10s; }
  .overlay.hidden .band:nth-child(4) { transition-delay: .15s; }
  .overlay.hidden { pointer-events: none; }

  /* ===== STAGE — NỘI DUNG ===== */
  .stage {
    position: absolute; inset: 0; z-index: 10;
    display: flex; flex-direction: column;
    align-items: center; justify-content: center;
    gap: 2rem;
    transition: opacity .35s ease;
  }
  .overlay.hidden .stage { opacity: 0; pointer-events: none; }
  .stage > * { pointer-events: auto; }

  /* ===== CHỮ TEXTURE 2 LỚP ===== */
  .greeting-wrap {
    position: relative; display: inline-block;
    isolation: isolate;   /* cô lập blend mode */
  }
  .greeting {
    display: block;
    font-size: clamp(3rem, 8vw, 6rem);
    font-weight: 800;
    letter-spacing: -.03em;
    line-height: 1;

    /* Lớp metal chảy */
    background: linear-gradient(
      100deg,
      #5a5a78 0%, #fff 18%, #7a7a9a 36%,
      #fff 54%, #5a5a78 72%, #fff 100%
    );
    background-size: 300% auto;
    -webkit-background-clip: text;
    background-clip: text;
    color: transparent;
    animation: textureFlow 5s linear infinite, fadeIn .9s .2s ease both;
    will-change: background-position, opacity;
  }
  @keyframes textureFlow { to { background-position: 300% 0; } }

  /* Lớp grain phủ */
  .greeting.grain {
    position: absolute; inset: 0;
    background: none;
    background-image:
      radial-gradient(rgba(255,255,255,.9) 1px, transparent 1px),
      radial-gradient(rgba(255,255,255,.5) 1px, transparent 1px);
    background-size: 3px 3px, 5px 5px;
    -webkit-background-clip: text;
    background-clip: text;
    color: transparent;
    mix-blend-mode: overlay;
    animation: grainShift .35s steps(3) infinite;
    pointer-events: none;
  }
  @keyframes grainShift {
    0%   { background-position: 0 0, 2px 2px; }
    33%  { background-position: 1px 1px, 3px 0; }
    66%  { background-position: -1px 1px, 1px 3px; }
    100% { background-position: 0 0, 2px 2px; }
  }
  @keyframes fadeIn {
    from { opacity: 0; } to { opacity: 1; }
  }

  /* ===== NÚT BẮT ĐẦU ===== */
  .start-btn {
    display: inline-flex; align-items: center; gap: .8rem;
    padding: 1rem 2.6rem;
    font-size: .82rem; font-weight: 600;
    letter-spacing: .32em; text-transform: uppercase;
    color: #fff; background: transparent;
    border: 1px solid rgba(255,255,255,.5);
    border-radius: 2px;
    cursor: pointer;
    transform: translateZ(0);
    transition: background .35s, color .35s, border-color .35s, transform .35s;
    will-change: transform;
    -webkit-tap-highlight-color: transparent;
    appearance: none; -webkit-appearance: none;
    outline: none; user-select: none;
    opacity: 0;
    animation: fadeUp .8s .7s ease forwards;
  }
  .start-btn:hover {
    background: #fff; color: #05060a; border-color: #fff;
    transform: translateZ(0) translateY(-2px);
  }
  .start-btn .arrow { display: inline-block; transition: transform .35s; }
  .start-btn:hover .arrow { transform: translateX(5px); }

  @keyframes fadeUp {
    from { opacity: 0; transform: translateY(18px); }
    to   { opacity: 1; transform: translateY(0); }
  }

  /* ===== REDUCED MOTION ===== */
  @media (prefers-reduced-motion: reduce) {
    *, *::before, *::after {
      animation: none !important;
      transition: none !important;
    }
    .greeting, .start-btn { opacity: 1; }
  }
</style>
</head>
<body>

<div class="page"><h2>Chào mừng bạn</h2></div>

<div class="overlay" id="overlay">
  <div class="band"></div>
  <div class="band"></div>
  <div class="band"></div>
  <div class="band"></div>

  <div class="stage">
    <div class="greeting-wrap">
      <span class="greeting">Xin chào.</span>
      <span class="greeting grain" aria-hidden="true">Xin chào.</span>
    </div>

    <button class="start-btn" id="startBtn">
      Bắt đầu <span class="arrow">→</span>
    </button>
  </div>
</div>

<script>
  const overlay = document.getElementById('overlay');
  const btn     = document.getElementById('startBtn');
  let done = false;

  btn.addEventListener('click', () => {
    if (done) return;
    done = true;
    btn.disabled = true;
    overlay.classList.add('hidden');
    setTimeout(() => overlay.remove(), 1400);
  });
</script>

</body>
</html>
```

---

Lưu ý

· Tôi không chắc hiệu ứng mix-blend-mode: overlay kết hợp background-clip: text hoạt động giống nhau trên mọi trình duyệt — cần test trên Chrome, Safari, Firefox.
· Tôi không chắc đạt 60 FPS ổn định trên mọi thiết bị — mix-blend-mode và background-clip: text có thể tốn compositor hơn so với animation transform thuần. Nên đo bằng DevTools Performance.
· Nếu thấy giật, có thể bỏ lớp grain hoặc đổi mix-blend-mode sang screen / soft-light.

🎯 Overlay texture = 4 dải blueprint grid + chữ "Xin chào." 2 lớp background-clip: text (kim loại chảy + grain blend) + nút outline vuông "Bắt đầu", ẩn bằng 4 dải trượt lẻ/chẵn lệch nhịp.
