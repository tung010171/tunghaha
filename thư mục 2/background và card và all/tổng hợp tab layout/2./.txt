Dưới đây là nội dung đầy đủ từ đầu đến cuối, đã bao gồm phần tổng quan cách làm và toàn bộ code (có bo góc tròn):

Tổng quan cách làm:

1. HTML: Tạo thẻ <nav> chứa các thẻ <a> (Icon + Label). Tạo thẻ <main> chứa các <section> nội dung tương ứng.
2. CSS: Dùng position: fixed; bottom: 0; để cố định thanh tab, kết hợp border-top-left-radius: 20px và border-top-right-radius: 20px để bo tròn 2 góc trên. Dùng padding-bottom: env(safe-area-inset-bottom) để tránh vạch home indicator (cần meta viewport viewport-fit=cover). Thêm padding-bottom cho <main> để nội dung không bị che.
3. JS: Bắt sự kiện click, xóa class active của tất cả tab/màn hình cũ, gắn class active cho tab/màn hình mới.

Code đầy đủ:

```html
<!DOCTYPE html>
<html lang="vi">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0, viewport-fit=cover">
  <style>
    * { box-sizing: border-box; margin: 0; padding: 0; }
    body { height: 100dvh; display: flex; flex-direction: column; overflow: hidden; font-family: sans-serif; background: #121212; color: white; }
    
    main { flex: 1; overflow-y: auto; padding: 20px 20px calc(60px + env(safe-area-inset-bottom) + 20px); }
    section { display: none; }
    section.active { display: block; }

    nav {
      position: fixed; bottom: 0; left: 0; width: 100%;
      height: calc(60px + env(safe-area-inset-bottom));
      padding-bottom: env(safe-area-inset-bottom);
      background: #1d4ed8;
      
      /* Bo góc trên */
      border-top-left-radius: 20px;
      border-top-right-radius: 20px;
      
      display: flex; justify-content: space-around; align-items: center;
    }
    a { text-decoration: none; color: rgba(255,255,255,0.6); font-size: 12px; display: flex; flex-direction: column; align-items: center; }
    a.active { color: white; }
  </style>
</head>
<body>
  <main>
    <section id="s1" class="active">Trang chủ</section>
    <section id="s2">Tìm kiếm</section>
  </main>

  <nav>
    <a href="#" class="active" data-target="s1">Icon1<br>Tab 1</a>
    <a href="#" data-target="s2">Icon2<br>Tab 2</a>
  </nav>

  <script>
    document.querySelectorAll('nav a').forEach(link => {
      link.addEventListener('click', (e) => {
        e.preventDefault();
        document.querySelectorAll('nav a, section').forEach(el => el.classList.remove('active'));
        link.classList.add('active');
        document.getElementById(link.dataset.target).classList.add('active');
      });
    });
  </script>
</body>
</html>
```

🎯 Tóm 1 câu: Làm Bottom Navigation Bar bằng cách dựng khung HTML với <nav> cố định đáy (có bo góc trên), <main> cuộn được, dùng CSS xử lý safe-area và JS gắn/gỡ class active để chuyển đổi màn hình.
