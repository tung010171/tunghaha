Flip Card 2 mặt tự động — Cách làm

Tổng quan 3 bước

Bước Việc làm
1 HTML: 1 khung .scene chứa 1 thẻ .card với 2 mặt .front / .back
2 CSS: 4 yếu tố làm lật được — perspective, preserve-3d, rotateY, backface-visibility
3 JS: chuỗi setTimeout lồng nhau + 2 biến timer, isAuto

---

Code

```html
<!DOCTYPE html>
<html lang="vi">
<head>
<meta charset="UTF-8">
<style>
  body {
    min-height: 100vh;
    display: flex;
    align-items: center;
    justify-content: center;
    background: #0a0e1a;
    font-family: system-ui, sans-serif;
    margin: 0;
  }

  /* ① Khung tạo không gian 3D */
  .scene {
    width: 320px;
    height: 420px;
    perspective: 1200px;
  }

  /* ② Thẻ có thể lật */
  .card {
    width: 100%;
    height: 100%;
    position: relative;
    transform-style: preserve-3d;
    transition: transform 0.8s;
    cursor: pointer;
  }

  /* ③ Khi có class .flipped → xoay 180° */
  .card.flipped {
    transform: rotateY(180deg);
  }

  /* ④ 2 mặt chồng nhau */
  .face {
    position: absolute;
    inset: 0;
    backface-visibility: hidden;
    border-radius: 24px;
    display: flex;
    align-items: center;
    justify-content: center;
    color: white;
    font-size: 1.4rem;
    font-weight: 700;
  }

  .front {
    background: linear-gradient(145deg, #6366f1, #a855f7);
  }

  .back {
    background: linear-gradient(145deg, #0ea5e9, #22d3ee);
    transform: rotateY(180deg);  /* úp sẵn 180° để hiện đúng hướng */
  }
</style>
</head>
<body>

  <div class="scene">
    <div class="card" id="card">
      <div class="face front">MẶT TRƯỚC</div>
      <div class="face back">MẶT SAU</div>
    </div>
  </div>

<script>
  const card = document.getElementById('card');
  let timer = null;
  let isAuto = true;

  function startCycle() {
    if (!isAuto) return;
    clearTimeout(timer);

    // ② Chờ 1 giây
    timer = setTimeout(() => {
      card.classList.add('flipped');           // ③ Lật sang mặt sau

      // ④ Dừng 3 giây đọc mặt sau
      timer = setTimeout(() => {
        card.classList.remove('flipped');      // ⑤ Lật về mặt trước

        // ⑥ Dừng 3 giây đọc mặt trước
        timer = setTimeout(() => {
          if (isAuto) startCycle();            // ⑦ Lặp lại
        }, 3000);
      }, 3000);
    }, 1000);
  }

  // Chạm → dừng auto, lật thủ công
  card.addEventListener('click', () => {
    isAuto = false;
    clearTimeout(timer);
    card.classList.toggle('flipped');

    // Sau 3 giây không chạm → bật lại auto
    timer = setTimeout(() => {
      isAuto = true;
      startCycle();
    }, 3000);
  });

  startCycle();
</script>
</body>
</html>
```

---

🎯 Tóm 1 câu

Làm bằng 1 thẻ 2 mặt trong HTML, 4 dòng CSS để lật được, và 1 hàm JS dùng setTimeout lồng nhau (1s → lật → 3s → lật về → 3s → lặp) với 2 biến timer và isAuto để dừng khi người dùng chạm.
