Full Glitch Text — Cách làm

🧩 Nguyên lý chung

Chồng 3 lớp chữ lên nhau, rồi cho 2 lớp trên giật lệch ngược chiều để mắt thấy như nhiễu RGB.

```
Lớp 3: ::after   → chữ hồng, cắt nửa dưới, giật ngược
Lớp 2: ::before  → chữ cyan, cắt nửa trên, giật xuôi
Lớp 1: .glitch   → chữ trắng (nền, đứng yên)
```

---

🪜 4 bước làm

Bước Việc Công cụ
1 Chữ gốc trắng + mốc định vị position: relative + color
2 Copy chữ sang 2 lớp phủ data-text + content: attr()
3 Cắt nửa trên / nửa dưới clip-path: polygon(...)
4 Giật lệch ngược nhịp @keyframes + translate + reverse

---

💻 Code chung chung

```html
<!DOCTYPE html>
<html lang="vi">
<head>
<meta charset="UTF-8">
<title>Full Glitch Text</title>
<style>
  body {
    margin: 0;
    min-height: 100vh;
    display: grid;
    place-items: center;
    background: #0a0e1a;
    font-family: 'Segoe UI', sans-serif;
  }

  /* ===== LỚP 1: CHỮ GỐC ===== */
  .glitch {
    position: relative;              /* mốc cho 2 lớp phủ */
    font-size: clamp(3rem, 14vw, 9rem);
    font-weight: 900;
    letter-spacing: 0.05em;
    color: #fff;                     /* trắng */
  }

  /* ===== LỚP 2 + 3: HAI LỚP PHỦ ===== */
  .glitch::before,
  .glitch::after {
    content: attr(data-text);        /* copy chữ từ HTML */
    position: absolute;
    inset: 0;                        /* phủ khít chữ gốc */
  }

  /* Lớp cyan — cắt nửa trên */
  .glitch::before {
    color: #22d3ee;
    clip-path: polygon(0 0, 100% 0, 100% 45%, 0 45%);
    animation: glitchShift 2s infinite;
  }

  /* Lớp hồng — cắt nửa dưới, chạy ngược */
  .glitch::after {
    color: #ec4899;
    clip-path: polygon(0 55%, 100% 55%, 100% 100%, 0 100%);
    animation: glitchShift 2s infinite reverse;
  }

  /* ===== GIẬT LỆCH ===== */
  @keyframes glitchShift {
    0%, 100% { transform: translate(0, 0); }
    20%      { transform: translate(-3px, 2px); }
    40%      { transform: translate(3px, -2px); }
    60%      { transform: translate(-2px, -1px); }
    80%      { transform: translate(2px, 1px); }
  }
</style>
</head>
<body>

  <!-- data-text phải TRÙNG với nội dung chữ -->
  <h1 class="glitch" data-text="GLITCH">GLITCH</h1>

</body>
</html>
```

---

🎯 Tóm 1 câu

Tạo chữ trắng gốc position: relative, dùng data-text + attr() để 2 lớp ::before/::after copy chữ sang, tô cyan/hồng rồi clip-path cắt nửa trên/dưới, cuối cùng cho translate giật lệch trong @keyframes — lớp hồng chạy reverse để lệch nhịp, tạo cảm giác nhiễu RGB.

---

Lưu ý: data-text="GLITCH" phải trùng khớp với nội dung chữ trong HTML, nếu không 2 lớp phủ sẽ hiện chữ khác chữ gốc. Code này thuần CSS, không cần JS.
