Tổng quan cách làm

Sequential Text Fill gồm 4 bước:

1. Tách chữ — mỗi chữ cái nằm trong 1 <span>, kèm data-char để ::before biết nội dung.
2. Chữ gốc = viền rỗng — dùng -webkit-text-stroke + color: transparent.
3. Lớp màu phủ lên — tạo ::before với gradient + background-clip: text, che bằng clip-path: inset(100% 0 0 0).
4. JS bật .active tuần tự — mỗi chu kỳ mở clip-path cho 1 chữ, quay vòng bằng %.

---

Code chung chung

```html
<!DOCTYPE html>
<html>
<head>
<style>
  .text { display: flex; gap: 0.05em; font-size: 6rem; font-weight: 900; }

  .text span {
    position: relative;
    color: transparent;
    -webkit-text-stroke: 2px #a855f7;
  }

  .text span::before {
    content: attr(data-char);
    position: absolute;
    inset: 0;
    background: linear-gradient(180deg, #ff5c8a, #38bdf8);
    -webkit-background-clip: text;
    background-clip: text;
    color: transparent;
    clip-path: inset(100% 0 0 0);      /* che màu */
    transition: clip-path 0.5s ease;
  }

  .text span.active::before {
    clip-path: inset(0 0 0 0);         /* mở màu */
  }
</style>
</head>
<body>

  <div class="text" id="text">
    <span data-char="H">H</span>
    <span data-char="E">E</span>
    <span data-char="L">L</span>
    <span data-char="L">L</span>
    <span data-char="O">O</span>
  </div>

<script>
  const spans = document.querySelectorAll('.text span');
  let i = 0;

  setInterval(() => {
    spans.forEach(s => s.classList.remove('active'));
    spans[i].classList.add('active');
    i = (i + 1) % spans.length;
  }, 800);
</script>
</body>
</html>
```

Muốn màu lên từ trái sang → đổi inset(100% 0 0 0) thành inset(0 100% 0 0).
Muốn giữ nhiều chữ cùng sáng → bỏ dòng spans.forEach(...remove...).
