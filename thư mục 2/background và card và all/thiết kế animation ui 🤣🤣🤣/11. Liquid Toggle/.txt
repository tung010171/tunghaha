Full Liquid Toggle — Cách làm

🧩 Nguyên lý chung

Dùng <input type="checkbox"> ẩn bên trong <label>. Khi click label → input được :checked. Dùng bộ chọn :checked + để đổi màu nền và trượt nút — không cần JS.

---

🪜 4 bước làm

Bước Việc Công cụ
1 Khung + input ẩn <label> + input { opacity: 0 }
2 Nền bo tròn .toggle-track + border-radius: 999px
3 Nút trượt ::before + translateX
4 Đổi màu khi bật :checked +

---

💻 Code chung chung

```html
<!DOCTYPE html>
<html lang="vi">
<head>
<meta charset="UTF-8">
<title>Liquid Toggle</title>
<style>
  body {
    margin: 0;
    min-height: 100vh;
    display: grid;
    place-items: center;
    background: #05070f;
    font-family: 'Segoe UI', sans-serif;
  }

  /* ===== 1. KHUNG + INPUT ẨN ===== */
  .toggle {
    position: relative;
    display: inline-block;
    width: 70px;
    height: 36px;
  }

  .toggle input {
    opacity: 0;                /* ẩn nhưng vẫn click được */
    width: 0;
    height: 0;
  }

  /* ===== 2. NỀN BO TRÒN ===== */
  .toggle-track {
    position: absolute;
    inset: 0;
    background: #1e293b;
    border-radius: 999px;
    cursor: pointer;
    transition: background 0.4s ease;
    overflow: hidden;
  }

  /* ===== 3. NÚT TRƯỢT ===== */
  .toggle-track::before {
    content: "";
    position: absolute;
    width: 28px;
    height: 28px;
    top: 4px;
    left: 4px;
    border-radius: 50%;
    background: #fff;
    box-shadow: 0 0 12px rgba(255, 255, 255, 0.5);
    transition: transform 0.4s cubic-bezier(0.34, 1.56, 0.64, 1);
    z-index: 2;
  }

  /* ===== 4. ĐỔI MÀU KHI BẬT ===== */
  .toggle input:checked + .toggle-track {
    background: linear-gradient(90deg, #a855f7, #ec4899);
  }

  .toggle input:checked + .toggle-track::before {
    transform: translateX(34px);
  }

  @media (prefers-reduced-motion: reduce) {
    .toggle-track,
    .toggle-track::before {
      transition-duration: 0.01ms !important;
    }
  }
</style>
</head>
<body>

  <label class="toggle">
    <input type="checkbox">
    <span class="toggle-track"></span>
  </label>

</body>
</html>
```

---

🎯 Tóm 1 câu

Dùng <label> bọc <input type="checkbox"> ẩn + .toggle-track bo tròn làm nền, nút trắng ::before trượt translateX(34px) khi :checked, và :checked + đổi nền sang gradient tím-hồng — mượt nhờ transition + cubic-bezier bật nhẹ, không cần JS.

---

Lưu ý: quãng trượt 34px = 70 (rộng) − 28 (nút) − 4 (trái) − 4 (phải). Nếu đổi kích thước khung/nút thì phải tính lại số này cho khớp. Bộ chọn + cần .toggle-track là anh em liền kề ngay sau input — nếu đổi thứ tự HTML thì phải đổi bộ chọn.
