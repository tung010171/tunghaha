Full Click-to-Pause Marquee — Cách làm

🧩 Nguyên lý chung

Dùng CSS tạo thanh marquee chạy tự động. Dùng JS gắn class .paused để tạm dừng, và setTimeout / clearTimeout để đếm 2 giây rồi tự chạy tiếp.

---

🪜 4 bước làm

Bước Việc Công cụ
1 Thanh dính mép trên position: fixed; top: 0
2 Track chạy liền mạch width: max-content + translateX(-50%)
3 Công tắc dừng class .paused + animation-play-state: paused
4 Đếm 2 giây click + setTimeout + clearTimeout

---

💻 Code chung chung

```html
<!DOCTYPE html>
<html lang="vi">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Click-to-Pause Marquee</title>
<style>
  * { margin: 0; padding: 0; box-sizing: border-box; }

  body {
    min-height: 100vh;
    background: #05070f;
    color: #fff;
    font-family: 'Segoe UI', sans-serif;
    padding-top: 44px;              /* chừa chỗ cho thanh */
  }

  /* ===== 1. THANH DÍNH MÉP TRÊN ===== */
  .top-marquee {
    position: fixed;
    top: 0; left: 0; right: 0;
    height: 44px;
    z-index: 999;
    display: flex;
    align-items: center;
    background: linear-gradient(90deg, #a855f7, #ec4899, #22d3ee, #a855f7);
    background-size: 300% 100%;
    animation: bgFlow 6s linear infinite;
    overflow: hidden;
    cursor: pointer;
    user-select: none;
  }

  @keyframes bgFlow {
    to { background-position: 300% 0; }
  }

  /* ===== 2. TRACK CHẠY ===== */
  .top-track {
    display: flex;
    gap: 2.5rem;
    width: max-content;             /* dài theo nội dung */
    animation: marqueeGo 18s linear infinite;
    will-change: transform;
  }

  @keyframes marqueeGo {
    to { transform: translateX(-50%); }  /* lặp 2 lần → liền mạch */
  }

  /* ===== 3. CÔNG TẮC DỪNG ===== */
  .top-track.paused {
    animation-play-state: paused;
  }

  /* ===== MỤC ===== */
  .top-item {
    font-size: 0.8rem;
    font-weight: 800;
    letter-spacing: 0.2em;
    text-transform: uppercase;
    color: #05070f;
    white-space: nowrap;
  }

  /* ===== NỘI DUNG DEMO ===== */
  .content {
    max-width: 700px;
    margin: 0 auto;
    padding: 4rem 1.5rem;
    text-align: center;
  }

  .content h1 {
    font-size: clamp(2rem, 8vw, 4rem);
    font-weight: 900;
    background: linear-gradient(90deg, #22d3ee, #a855f7, #ec4899);
    -webkit-background-clip: text;
    background-clip: text;
    color: transparent;
    margin-bottom: 1.5rem;
  }

  .status {
    font-size: 0.75rem;
    letter-spacing: 0.25em;
    text-transform: uppercase;
    color: #22d3ee;
  }

  @media (prefers-reduced-motion: reduce) {
    .top-marquee, .top-track {
      animation-duration: 0.01ms !important;
    }
  }
</style>
</head>
<body>

  <div class="top-marquee" id="marquee">
    <div class="top-track" id="track">
      <!-- Nội dung lặp 2 lần để chạy liền mạch -->
      <span class="top-item">★ HELLO WORLD</span>
      <span class="top-item">★ WELCOME TO MY SITE</span>
      <span class="top-item">★ DESIGN & ANIMATION</span>
      <span class="top-item">★ CYBERPUNK THEME</span>

      <span class="top-item">★ HELLO WORLD</span>
      <span class="top-item">★ WELCOME TO MY SITE</span>
      <span class="top-item">★ DESIGN & ANIMATION</span>
      <span class="top-item">★ CYBERPUNK THEME</span>
    </div>
  </div>

  <main class="content">
    <h1>CLICK-TO-PAUSE MARQUEE</h1>
    <p class="status" id="status">● ĐANG CHẠY TỰ ĐỘNG</p>
  </main>

<script>
  const marquee = document.getElementById('marquee');
  const track   = document.getElementById('track');
  const status  = document.getElementById('status');

  let resumeTimer = null;             // biến giữ timer

  /* ===== 4. CLICK → DỪNG + ĐẾM 2 GIÂY ===== */
  marquee.addEventListener('click', () => {
    track.classList.add('paused');    // dừng
    status.textContent = '⏸ ĐANG DỪNG — chờ 2 giây';

    clearTimeout(resumeTimer);        // reset đếm nếu click tiếp

    resumeTimer = setTimeout(() => {  // hết 2s → chạy tiếp
      track.classList.remove('paused');
      status.textContent = '● ĐANG CHẠY TỰ ĐỘNG';
    }, 2000);
  });
</script>

</body>
</html>
```

---

🎯 Tóm 1 câu

Tạo thanh position: fixed mép trên + track width: max-content chạy translateX(-50%) liền mạch, rồi dùng class .paused đổi animation-play-state và JS click + setTimeout/clearTimeout để dừng 2 giây rồi tự chạy tiếp.

---

Lưu ý: Nội dung track phải lặp đủ 2 lần để translateX(-50%) không thấy khoảng trống. padding-top của body nên bằng hoặc lớn hơn chiều cao thanh (44px) để không che nội dung.
