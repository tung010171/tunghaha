Full Neon Flicker — Cách làm

🧩 Nguyên lý chung

Dùng CSS tô chữ cyan + gắn text-shadow nhiều lớp để tạo quầng sáng. Rồi cho opacity và text-shadow nhảy theo mốc trong @keyframes — tạo cảm giác đèn neon chập chờn.

---

🪜 3 bước làm

Bước Việc Công cụ
1 Chữ cyan đậm color + font-weight
2 Quầng sáng neon text-shadow nhiều lớp
3 Nhấp nháy @keyframes + opacity + animation: infinite

---

💻 Code chung chung

```html
<!DOCTYPE html>
<html lang="vi">
<head>
<meta charset="UTF-8">
<title>Neon Flicker</title>
<style>
  body {
    margin: 0;
    min-height: 100vh;
    display: grid;
    place-items: center;
    background: #05070f;
    font-family: 'Segoe UI', sans-serif;
  }

  /* ===== 1. CHỮ NEON ===== */
  .neon {
    font-size: clamp(2rem, 8vw, 4rem);
    font-weight: 900;
    letter-spacing: 0.15em;
    color: #22d3ee;                 /* cyan */
    text-shadow:                    /* quầng sáng 4 lớp */
      0 0 4px  #22d3ee,
      0 0 12px #22d3ee,
      0 0 24px #22d3ee,
      0 0 48px #22d3ee;

    /* ===== 3. NHẤP NHÁY ===== */
    animation: flicker 3s infinite;
  }

  @keyframes flicker {
    /* Đoạn SÁNG */
    0%, 18%, 22%, 25%, 53%, 57%, 100% {
      opacity: 1;
      text-shadow:
        0 0 4px  #22d3ee,
        0 0 12px #22d3ee,
        0 0 24px #22d3ee,
        0 0 48px #22d3ee;
    }
    /* Đoạn TỐI */
    20%, 24%, 55% {
      opacity: 0.4;
      text-shadow: none;
    }
  }

  @media (prefers-reduced-motion: reduce) {
    .neon { animation-duration: 0.01ms !important; }
  }
</style>
</head>
<body>

  <h1 class="neon">NEON</h1>

</body>
</html>
```

---

🎯 Tóm 1 câu

Tạo chữ color: cyan + text-shadow 4 lớp cùng màu bán kính tăng dần để có quầng neon, rồi dùng @keyframes cho opacity và text-shadow nhảy giữa các mốc sáng/tối (18-25%, 53-57%) với animation: infinite — tạo cảm giác đèn neon chập chờn.

---

Lưu ý: các mốc % trong @keyframes là chọn tùy ý — đổi số sẽ ra nhịp chập chờn khác. text-shadow: none ở mốc tối làm quầng biến mất đột ngột, tạo cảm giác đèn tắt.
