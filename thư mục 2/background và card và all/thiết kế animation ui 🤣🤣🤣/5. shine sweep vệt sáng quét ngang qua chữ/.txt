Full Shine Sweep — Cách làm tổng quan

🧩 Nguyên lý chung

Xếp 3 lớp chồng lên nhau, mỗi lớp một vai trò, rồi cho lớp trên cùng chạy ngang qua chữ.

```
Lớp 3: ::after   → vệt sáng + sợi texture  (chạy ngang)
Lớp 2: ::before  → vân xước mờ              (đứng yên)
Lớp 1: .hello    → chữ gradient kim loại    (nền)
```

Ba lớp hòa vào nhau nhờ mix-blend-mode: overlay — thay vì đè cứng lên nhau.

---

🪜 4 bước làm

Bước Việc Công cụ
1 Vẽ chữ có màu kim loại linear-gradient + background-clip: text
2 Phủ vân xước lên chữ ::before + repeating-linear-gradient
3 Tạo vệt sáng có sợi ::after + 2 gradient chồng
4 Cho vệt sáng chạy ngang translateX trong @keyframes

---

💻 Code chung chung (khung sườn)

```html
<!DOCTYPE html>
<html lang="vi">
<head>
<meta charset="UTF-8">
<title>Full Shine Sweep</title>
<style>
  body {
    margin: 0;
    min-height: 100vh;
    display: flex;
    align-items: center;
    justify-content: center;
    background: #0a0e1a;
  }

  /* Khung chứa */
  .hello-wrap {
    position: relative;
    overflow: hidden;
  }

  /* ===== LỚP 1: CHỮ KIM LOẠI ===== */
  .hello {
    font-family: 'Segoe UI', sans-serif;
    font-size: clamp(3rem, 14vw, 9rem);
    font-weight: 900;
    letter-spacing: 0.05em;
    color: transparent;
    background: linear-gradient(180deg, #f5d0fe, #a855f7, #6b21a8, #c084fc);
    -webkit-background-clip: text;
    background-clip: text;
  }

  /* ===== LỚP 2: VÂN XƯỚC ===== */
  .hello-wrap::before {
    content: "";
    position: absolute;
    inset: 0;
    background-image:
      repeating-linear-gradient(45deg,
        rgba(255,255,255,0.03) 0 1px, transparent 1px 3px),
      repeating-linear-gradient(-45deg,
        rgba(0,0,0,0.05) 0 1px, transparent 1px 3px);
    mix-blend-mode: overlay;
    pointer-events: none;
    z-index: 2;
  }

  /* ===== LỚP 3: VỆT SÁNG CÓ SỢI ===== */
  .hello-wrap::after {
    content: "";
    position: absolute;
    inset: -20% -10%;
    background:
      linear-gradient(115deg,
        transparent 35%,
        rgba(255,255,255,0.9) 48%,
        #fff 50%,
        rgba(255,255,255,0.9) 52%,
        transparent 65%),
      repeating-linear-gradient(115deg,
        rgba(255,255,255,0.15) 0 2px, transparent 2px 6px);
    background-blend-mode: overlay;
    transform: translateX(-120%);
    animation: shine 3s ease-in-out infinite;
    mix-blend-mode: overlay;
    pointer-events: none;
    z-index: 3;
  }

  /* ===== ĐIỀU KHIỂN VỆT SÁNG ===== */
  @keyframes shine {
    0%, 60% { transform: translateX(-120%); }
    85%     { transform: translateX(120%);  }
    100%    { transform: translateX(120%);  }
  }
</style>
</head>
<body>

  <div class="hello-wrap">
    <div class="hello">HELLO</div>
  </div>

</body>
</html>
```

---

🎯 Tóm 1 câu

Xếp 3 lớp — chữ gradient kim loại → vân xước (::before) → vệt sáng có sợi (::after) — rồi cho lớp trên chạy ngang bằng translateX + @keyframes shine, tất cả hòa quyện nhờ mix-blend-mode: overlay.

---

Lưu ý: background-clip: text cần tiền tố -webkit- để chạy tốt trên Safari và một số trình duyệt cũ.
