Guidelines

Best Practices

Nên làm (Do)

  • Dùng token thay vì hardcode giá trị
  • Tái sử dụng component, không viết lại
  • Giữ variant tối thiểu, chỉ thêm khi cần
  • Đặt tên token theo ngữ nghĩa (primary, danger)
  • Test component trên Storybook trước khi dùng

Không nên (Don't)

  • Hardcode màu, font, spacing rải rác
  • Tạo variant mới chỉ vì 1 chỗ cần khác
  • Override style bằng !important
  • Đặt tên token mơ hồ (blue1, red2)
  • Copy-paste component rồi sửa riêng

Đúng

.btn-primary {
  background: var(--color-primary);
  padding: var(--space-3) var(--space-5);
  border-radius: var(--radius-lg);
}

Sai

.btn-primary {
  background: #6366f1;
  padding: 12px 20px;
  border-radius: 8px;
}
